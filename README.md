# Simulador de cafetería

Proyecto realizado como actividad de estudio para practicar funciones y lógica de programación con JavaScript.

## Descripción

El simulador permite registrar un pedido de cafés. Primero solicita el nombre del usuario y la cantidad de cafés que desea comprar.

Luego, por cada café, permite elegir entre:

- Opción 1: café con azúcar.
- Opción 2: café sin azúcar.
- Cualquier otro valor: opción inválida.

Al finalizar, muestra un mensaje confirmando que el pedido fue registrado.

##  Funcionamiento

El programa sigue tres etapas:

1. **Entrada de datos:** utiliza `prompt()` para solicitar el nombre, la cantidad de cafés y las opciones del pedido.
2. **Procesamiento:** valida cada opción mediante condicionales y funciones.
3. **Salida de datos:** muestra los resultados en la consola y confirma el pedido mediante `alert()`.

##  Conceptos utilizados

- Variables declaradas con `const` y `let`.
- Conversión de texto a número con `Number()`.
- Funciones declaradas.
- Funciones expresadas.
- Funciones flecha.
- Parámetros y argumentos.
- Retorno de valores con `return`.
- Condicionales `if`, `else if` y `else`.
- Ciclo de repetición `for`.
- Interacción mediante `prompt()`, `console.log()` y `alert()`.
- Separación del programa en funciones de entrada, procesamiento y salida.
